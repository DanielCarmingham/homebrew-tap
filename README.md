# homebrew-tap

Homebrew formulae for [Daniel Carmingham](https://github.com/DanielCarmingham)'s tools.

```bash
brew install DanielCarmingham/tap/dextui
```

`Formula/` is written automatically by [dist](https://github.com/axodotdev/cargo-dist)
when a release is tagged in the tool's own repository. Don't hand-edit anything
in there -- the next release overwrites it.

| formula | source |
| --- | --- |
| `dextui` | [DanielCarmingham/dextui](https://github.com/DanielCarmingham/dextui) -- a terminal UI for browsing and triaging [dex](https://dex.rip/) tasks |
